# GraphKer 資料下載與匯入指南

本文說明如何從 NVD/MITRE 下載資料、準備 Neo4j import 目錄，並透過 GraphKer 進行 APOC 檔案模式匯入（或直寫模式）。指令皆以 `uv run python main.py` 為例。

## 環境前置
- Python/uv 已可執行本專案。
- Neo4j 已啟用 APOC 且允許讀取檔案：`apoc.import.file.enabled=true`，Neo4j 端的 import 目錄（預設 `/var/lib/neo4j/import`）需由 `neo4j` 使用者可讀。
- 需要遠端匯入時，確認 Neo4j 端的檔案路徑（例如 `/var/lib/neo4j/import`）與本機下載目錄（例如 `IMPORT_PATH`）是否相同或已掛載。
- NVD 來源/API 設定可放在 `.env`：`NVD_SOURCE=mirror` 或 `api`，`NVD_API_KEY=...`（需要時），`NVD_YEARS=2023,2024` 或 `all`。

## 步驟一：下載與預處理
```bash
# 僅下載與切分（不寫入 Neo4j）
uv run python main.py -d IMPORT_PATH --download-only
# 匯出內容：IMPORT_PATH/nist/cve|cpe/splitted、mitre_cwe/splitted、mitre_capec/splitted 以及 CypherScripts/*.cypher
```

## 步驟二：把檔案放到 Neo4j 可讀路徑
- 若 Neo4j 在 Docker 且路徑未掛載，使用：
  ```bash
  docker cp IMPORT_PATH/. neo4j:/var/lib/neo4j/import
  docker exec neo4j chown -R neo4j:neo4j /var/lib/neo4j/import
  ```
- 若已用 volume 掛載，確認掛載路徑與 Neo4j 的 import 目錄一致。
- 遠端路徑與本機路徑不一致時，後面匯入需提供 `--apoc-import-path` 指向 Neo4j 端可見的路徑。

## 步驟三：執行匯入
常用情境（Neo4j 端路徑與本機不同）：
```bash
uv run python main.py \
  -u bolt://<neo4j_host>:7687 -n <user> -p <password> \
  -d IMPORT_PATH \                 # 本機已下載的資料路徑
  --apoc-import-path /var/lib/neo4j/import \  # Neo4j 端可見路徑
  --reuse-downloads                # 不重新下載
```

其他常用參數：
- `--direct-ingest`：改走直寫模式（CWE/CAPEC 支援；CVE/CPE 仍需檔案）。在無法讀取 import 目錄時可用來測試。
- `--skip-cpe`、`--skip-cve`：跳過特定資料集。
- `--direct-limit N`：直寫模式下限制筆數，快速試跑。

> 提示：匯入 log 末尾的 APOC summary（batches、failedBatches 等）可確認每檔案處理狀態；`cypher-shell` 顯示的 "No changes" 只代表讀寫摘要，不影響查詢結果。

## 步驟四：快速驗證（cypher-shell）
```cypher
MATCH (c:CVE) RETURN c.Name AS id, c.Published_Date LIMIT 5;
MATCH (p:CPE) RETURN p.uri LIMIT 5;
MATCH (w:CWE) RETURN w.Name, w.Description LIMIT 5;
MATCH (a:CAPEC) RETURN a.Name, a.Typical_Severity LIMIT 5;

MATCH (c:CVE)-[r:applicableIn]->(p:CPE)
RETURN c.Name AS cve, p.uri AS cpe, r.Vulnerable AS vuln LIMIT 5;

MATCH (c:CVE)-[:Problem_Type]->(w:CWE)
RETURN c.Name AS cve, w.Name AS cwe LIMIT 5;
```

## 常見問題
- **匯入時目錄缺失警告**：本機 `-d` 路徑找不到檔案，或 Neo4j 端看不到該路徑。確保下載完成，且 `--apoc-import-path` 指向 Neo4j 真正可讀的 import 路徑。
- **未返回 APOC summary**：檢查檔案是否存在、Neo4j 是否允許 `apoc.import.file.enabled=true`，路徑前綴是否為 `file:///` 並指向 Neo4j 端可讀的位置。
